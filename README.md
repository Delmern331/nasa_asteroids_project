# Аналіз навколоземних астероїдів (NASA NEO) 

## Назва та мета проєкту
**Веб-застосунок для аналізу навколоземних астероїдів.** Мета проєкту — автоматизувати отримання даних про астероїди, які наближаються до Землі, перетворити їх у зручний табличний формат, зберегти результати та надати користувачу інтерактивний веб-інтерфейс для аналізу за допомогою графіків і метрик.

## Джерело даних
Дані отримуються через відкритий API космічного агентства: **NASA Near Earth Object Web Service (NEO API)**. 
Використовується ендпоінт: `https://api.nasa.gov/neo/rest/v1/feed`.

## Структура даних
Отримані JSON-дані парсяться та конвертуються у Pandas DataFrame, який потім зберігається у файл `asteroids.csv`. Таблиця має такі колонки:
- `name` — назва астероїда;
- `date` — дата зближення із Землею;
- `is_hazardous` — статус потенційної небезпеки (True/False);
- `diameter_min_m`, `diameter_max_m` — мінімальний та максимальний діаметр у метрах;
- `diameter_avg_m` — обчислений середній діаметр;
- `velocity_kmh` — швидкість відносно Землі (км/год);
- `miss_distance_km` — відстань, на якій пролітає астероїд (км);
- `orbiting_body` — тіло, біля якого пролітає (зазвичай Earth).

## Основні можливості застосунку
1. **Гнучкий вибір дат:** Користувач може завантажити дані за попередні 7 днів, наступні 7 днів або обрати власний діапазон дат. Програма автоматично обходить обмеження NASA (макс. 7 днів за запит) шляхом розбиття великих діапазонів на серію менших запитів.
2. **Зведена статистика:** Миттєвий підрахунок загальної кількості, виявлення найшвидшого, найбільшого та найближчого до Землі астероїда.
3. **Експорт даних:** Автоматичне збереження очищених даних у `asteroids.csv`.

## Опис реалізованих графіків
Візуалізація реалізована за допомогою бібліотеки Plotly Express:
1. **Стовпчаста діаграма (Кількість за днями):** Показує динаміку наближення астероїдів по конкретних датах.
2. **Кругова діаграма (Небезпечні vs Безпечні):** Відображає частку потенційно небезпечних космічних об'єктів.
3. **Горизонтальна діаграма (Топ-10 найближчих):** Рейтинг 10 астероїдів, які пролетять найближче до Землі.
4. **Діаграма розсіювання (Розмір vs Відстань):** Дозволяє побачити кореляцію між розміром об'єкта, його швидкістю (розмір точки) та відстанню до Землі.
